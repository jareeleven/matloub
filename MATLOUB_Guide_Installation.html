Ce guide d'installation
Suivez les étapes dans l'ordre
1
Créer un compte Google Firebase
Gratuit — Aucune carte bancaire requise pour commencer

Firebase est le service de base de données de Google. Le plan gratuit (Spark) suffit largement pour démarrer MATLOUB.

🌐 Ouvrir Firebase Console
Plan gratuit Firebase (Spark) inclut :
• 50 000 lectures / jour
• 20 000 écritures / jour
• 1 GB de stockage Firestore
• 5 GB de Firebase Storage (photos)
• SSL/HTTPS automatique
2
Créer un nouveau projet Firebase
2 minutes
  1. Cliquez sur "Créer un projet"
  2. Nom du projet : matloub-oran (ou matloub-com)
  3. Désactivez Google Analytics (optionnel)
  4. Cliquez "Créer le projet"
  5. Attendez la création (~30 secondes)
✅ Votre projet Firebase est créé ! Notez bien le Project ID (ex: matloub-oran-12345)
3
Ajouter une application Web
Récupérer les clés de configuration
  1. Dans la console Firebase, cliquez sur l'icône </> (Web)
  2. Nom de l'app : MATLOUB Web
  3. Ne cochez PAS "Firebase Hosting" pour l'instant
  4. Cliquez "Enregistrer l'application"
  5. Firebase vous donne un bloc de code — copiez-le

Vous obtiendrez quelque chose comme :

// Votre configuration Firebase (exemple) const firebaseConfig = { apiKey: "AIzaSyBxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx", authDomain: "matloub-oran.firebaseapp.com", projectId: "matloub-oran-12345", storageBucket: "matloub-oran-12345.appspot.com", messagingSenderId: "123456789012", appId: "1:123456789012:web:abcdef1234567890" };
⚠️ Gardez ces clés en sécurité. Ne les partagez pas publiquement sur GitHub.
4
Configurer Firestore Database
La base de données des professionnels
  1. Dans le menu gauche Firebase : Build → Firestore Database
  2. Cliquez "Créer une base de données"
  3. Choisissez "Mode production"
  4. Région : choisissez europe-west3 (Frankfurt, plus proche de l'Algérie)
  5. Cliquez "Activer"

Configurer les règles de sécurité Firestore :

Cliquez sur l'onglet "Règles" et collez :

// Règles Firestore MATLOUB rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Professionnels — lecture publique, écriture filtrée match /professionals/{docId} { allow read: if true; allow create: if request.resource.data.keys().hasAll([ 'name', 'job', 'phone', 'status', 'joinDate' ]) && request.resource.data.name.size() <= 100 && request.resource.data.job.size() <= 100; allow update: if request.resource.data.diff(resource.data) .affectedKeys().hasOnly(['status', 'available', 'bio', 'photos', 'phone', 'reviews', 'reports', 'reportDetails', 'noResponseReports', 'views', 'messages', 'updatedAt', 'lastLogin', 'emailVerified', 'unavailReason']); allow delete: if false; // Suppression via Admin uniquement } // Trafic — écriture publique, lecture admin match /traffic/{date} { allow write: if true; allow read: if true; } // Clients match /clients/{docId} { allow read, write: if true; } } }
✅ Publiez les règles en cliquant "Publier"
5
Configurer Firebase Storage (Photos)
Pour les photos de profil des professionnels
  1. Menu Firebase : Build → Storage
  2. Cliquez "Commencer"
  3. Choisissez "Mode production"
  4. Même région : europe-west3

Règles Storage (onglet Règles) :

rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /photos/{allPaths=**} { allow read: if true; allow write: if request.resource.size < 5 * 1024 * 1024 && request.resource.contentType.matches('image/.*'); } } }
✅ Les photos seront stockées automatiquement sur Firebase Storage
6
Coller votre configuration dans les fichiers
La partie la plus importante !

Ouvrez chacun de vos 2 fichiers HTML avec un éditeur de texte (Notepad++, VSCode) et cherchez cette section :

// ⚠️ REMPLACEZ CES VALEURS PAR VOTRE PROPRE PROJET FIREBASE const FIREBASE_CONFIG = { apiKey: "VOTRE_API_KEY", ← Remplacez authDomain: "votre-projet.firebaseapp.com", ← Remplacez projectId: "votre-projet-id", ← Remplacez storageBucket: "votre-projet.appspot.com", ← Remplacez messagingSenderId: "VOTRE_SENDER_ID", ← Remplacez appId: "VOTRE_APP_ID" ← Remplacez };
⚠️ Faites cette modification dans LES DEUX fichiers : l'app principale ET le panneau admin. Ils doivent avoir exactement la même configuration.
💡 Astuce : Utilisez Ctrl+H (Rechercher/Remplacer) dans Notepad++ pour remplacer "VOTRE_API_KEY" par votre vraie clé rapidement.

8
Sécuriser l'accès Admin
Empêcher les inconnus d'accéder à votre panneau

Si vous utilisez Hostinger/cPanel, protégez le dossier /admin avec un mot de passe htpasswd :

  1. Dans cPanel → Directory Privacy
  2. Trouvez le dossier admin
  3. Cochez "Password protect this directory"
  4. Créez un utilisateur avec un mot de passe fort
🔐 Identifiants de connexion Admin MATLOUB :
Login : admin
Mot de passe : Admin@2024
⚠️ Changez ce mot de passe dans Paramètres → Changer mot de passe
